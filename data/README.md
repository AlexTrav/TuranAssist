# TuranAssist – данные

Корпус текстов, из которого собирается база ответов чат-бота: страницы сайта
[turan.edu.kz](https://turan.edu.kz) и нормативные документы университета на русском,
казахском и английском языках.

## Сбор корпуса

Запускается в Docker, локальное окружение Python не нужно:

```bash
make collect          # страницы сайта и нормативные документы
make collect-pages    # только страницы сайта
make collect-docs     # только PDF-документы
make tuition          # цены по программам -> knowledge/tuition.yaml (после сбора страниц – автоматически)
```

Скрипт представляется собственным User-Agent и делает паузу 1 с между запросами,
полный сбор занимает несколько минут.

## Как устроен сбор

- Сайт построен на Inertia.js: весь контент страницы лежит JSON-ом в атрибуте `data-page`,
  поэтому HTML не парсится – скрипт достаёт JSON и обходит его, собирая заголовки, текст
  и ссылки на документы (`collect/extract.py`).
- Языковые версии: казахская – без префикса, русская – `/ru/...`, английская – `/en/...`.
- Список страниц сгруппирован по темам будущих интентов (`collect/config.py`):
  поступление, оплата и гранты, учебный процесс, факультеты, студенческая жизнь,
  международное сотрудничество, об университете.
- В тексте остаются ссылки на документы и внешние ресурсы (онлайн-заявка в ЦОС, правила
  проживания, регистрация на экзамены) – бот отправляет по ним пользователя туда, где
  действие выполняется на самом деле. Внутренняя навигация по сайту отбрасывается.
- Персональные данные не собираются: таблицы, в заголовке которых есть ФИО
  («Ф.И.О.», «аты-жөні», «Full name»), отбрасываются на любой странице, а на странице
  заявок на вакантные гранты – все таблицы (списки претендентов с GPA).
- Документы скачиваются по ссылкам со страниц сайта: PDF с Google Drive (текст извлекается
  через PyMuPDF построчно по координатам слов – так строки таблиц, например событие и дата
  календаря, не разрываются) и Word-файлы Google Docs (текстовый экспорт). Собираются:
  академическая политика 2025–2026, положение о контроле успеваемости, кодекс студента,
  правила приёма 2026–2027, академические календари 2026–2027 (бакалавриат, профильная
  и научно-педагогическая магистратура), положения о переводе, восстановлении и отчислении
  и об академических отпусках.
- Не собираются: политика использования ИИ (владелец запретил скачивание файла),
  протокол конкурсной комиссии и списки претендентов на гранты (персональные данные),
  путеводитель студента (скан без текстового слоя, нужен OCR), расписания занятий
  (меняются каждый семестр). На все эти файлы в корпусе остаются ссылки – бот отдаёт их
  пользователю как есть.
- Запросы повторяются до 3 раз при обрыве соединения; страницы без версии на каком-то
  языке (сайт зацикливает редирект) помечаются в манифесте как `missing`, а не как ошибка.

## Структура

```
data/
  collect/           – скрипты сбора (config, extract, site, documents)
  corpus/            – извлечённый текст, хранится в git
    site/<язык>/     – страницы сайта в markdown, файл назван коротким id из config.py
    docs/<язык>/     – текст нормативных документов
    manifest.json    – источник, язык, тема, объём и дата сбора каждого файла
  raw/               – сырые JSON страниц и PDF, в git не попадает
  knowledge/         – база ответов, справочник программ и цены по ним (см. knowledge/README.md)
```

Каждый файл корпуса начинается со ссылки на источник и даты сбора – по ним бот
отправляет пользователя к первоисточнику, а устаревшие данные легко обновить повторным сбором.
