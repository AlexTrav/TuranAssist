# TuranAssist – база ответов

Интенты чат-бота и курируемые ответы на русском, казахском и английском языках.
Бот не генерирует текст: модель определяет интент вопроса, а ответ берётся отсюда –
так в ответах нет выдуманных фактов об университете.

## Структура

```
knowledge/
  groups.yaml          – 8 групп интентов (порядок и названия для интерфейса)
  intents/<группа>.yaml – интенты группы: id, название, ответ на ru/kk/en, источники
  programs.yaml        – 32 образовательные программы: названия на ru/kk/en и варианты написания
  tuition.yaml         – цены по программам и формам обучения (генерируется, руками не править)
```

Формат интента:

```yaml
- id: tuition_bachelor                      # уникальный идентификатор – метка класса для модели
  title: {ru: ..., kk: ..., en: ...}        # короткое название – для кнопок-подсказок
  sources: [tuition-fee]                    # id страниц и документов из corpus/manifest.json
  answer:
    ru: |
      ...
```

Ссылку «Подробнее» бот строит по первому источнику на языке пользователя
(`https://turan.edu.kz/<slug>`, `/ru/<slug>` или `/en/<slug>`), поэтому адреса страниц
сайта в тексте ответов не дублируются.

## Состав

53 интента в 8 группах: общение (4), поступление (11), магистратура и докторантура (3),
стоимость и оплата (3), гранты и скидки (7), учебный процесс (13), студенческая жизнь (7),
об университете (5). Вопросы вне этих тем интентами не являются – их отсекает порог
уверенности модели, и бот честно отвечает «не понял».

## Цена по конкретной программе

На вопрос «Сколько стоит ВТиПО?» бот отвечает ценой именно этой программы, а не общей таблицей.
Программа извлекается из вопроса по programs.yaml: в liases – основы слов и сокращения
(«втипо», «вт и по», «программист», «ис», «рэт», «есептеу техника», «software engineer»).
Слово из 4+ букв совпадает по началу, короткое – только целиком («ис» не находится в «история»),
при пересечении побеждает самое длинное совпадение («международное право», а не «право»).

Цены 	uition.yaml генерирует make tuition из собранной страницы «Стоимость обучения»
(collect/tuition.py): если на сайте появится программа, которой нет в programs.yaml,
или пропадёт раздел таблицы, генерация остановится с ошибкой, а make check сообщит,
что 	uition.yaml устарел.

## Правила

- Каждый факт взят из корпуса (`data/corpus`) – из страницы или документа, указанного в `sources`.
- Изменчивые данные (цены, сроки, наличие мест) привязаны к году или дате, на которую они верны.
- Казахские и английские тексты переведены без сверки с носителем языка – для реального
  использования их стоит вычитать.
- Только среднее тире «–».

## Проверка

```bash
cd data && make check
```

Проверяются структура файлов, уникальность id, наличие названия и ответа на всех трёх
языках, существование источников в корпусе и отсутствие длинного тире; для программ – названия
на трёх языках и актуальность 	uition.yaml относительно корпуса.
