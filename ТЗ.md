# Задание 1. Разработать приложение

**Дисциплина:** Технологии разработки программного обеспечения для систем реального времени
**Срок сдачи:** 19 октября, 23:59
**Баллы:** 100
**Способ отправки:** загрузка файла

## Рубежное задание

Разработать систему (программу или приложение) «Чат-бот с NLP (Natural Language Processing)».

## Описание

Создание чат-бота, который отвечает на вопросы в заданной области
(например, консультант интернет-магазина или ассистент для студентов).

## Этапы выполнения

1. Сбор текстовых данных (FAQ, описания товаров, лекционные материалы).
2. Предобработка текста: токенизация, лемматизация, удаление стоп-слов.
3. Построение модели на основе Bag-of-Words, TF-IDF и/или трансформеров (BERT, GPT).
4. Интеграция модели в телеграм-бот или веб-приложение.
5. Тестирование на реальных сценариях общения.

## Навыки

- Основы NLP и векторизации текста.
- Работа с современными трансформерными моделями.
- Создание прикладных диалоговых систем.
