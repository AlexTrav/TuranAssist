# TuranAssist – фронтенд

Vue 3 + TypeScript + Tailwind CSS 4 + Vite; интерфейс на русском, казахском и английском (vue-i18n),
светлая и тёмная тема, адаптивная вёрстка, иконки Heroicons.

## Страницы

- **Главная** – что умеет бот, как он работает, карточки тем (клик – вопрос сразу уходит в чат), ссылка на Telegram.
- **Чат** – веб-чат с ботом: индикатор «печатает», уверенность модели и время ответа под сообщением,
  ссылка на первоисточник, кнопки-подсказки, когда бот не уверен; понимает уточнения («а в магистратуре?»)
  и помечает такие ответы; история хранится только в браузере.
- **Производительность** – живые метрики бэкенда каждые 3 секунды: p50/p95/p99 задержки, время модели
  (e5 и TF-IDF), доля распознанных вопросов, память относительно лимита 512 МБ, время загрузки модели,
  график последних запросов.
- **О проекте** – конвейер проекта, сравнение моделей с 95% доверительными интервалами (с бэкенда),
  все 53 темы, стек, ограничения.

При открытии сайт сразу «будит» бэкенд; если бесплатный Render просыпается, показывается баннер.

## Запуск

Только в Docker, локальный `node_modules` не нужен:

```bash
make test   # автотесты Vitest
make build  # проверка типов, сборка Vite и образ nginx
make dev    # dev-сервер на http://localhost:5173 (бэкенд – http://localhost:8000)
make lock   # обновить package-lock.json после правки package.json
```

В образе nginx раздаёт статику и проксирует `/api/*` на контейнер `backend` (docker-compose).
Для GitHub Pages адрес бэкенда на Render передаётся при сборке (`VITE_API_BASE_URL`, `BASE`).

## Структура

```
src/
  api/client.ts      – запросы к API с таймаутом и кодами ошибок
  composables/       – useChat, useServerStatus, useLiveMetrics, useTheme, useLocale
  components/        – шапка, подвал, пузырь сообщения, карточка метрики, график задержек, баннер
  views/             – Главная, Чат, Производительность, О проекте
  locales/           – тексты ru/kk/en (kk и en типизированы по ru – пропущенный ключ ломает сборку)
  utils/             – форматирование чисел и построение графика
```
