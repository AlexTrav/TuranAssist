# TuranAssist – фронтенд

Vue 3 + TypeScript + Tailwind CSS 4 + Vite; интерфейс на русском, казахском и английском (vue-i18n),
светлая и тёмная тема, адаптивная вёрстка от 360 px, иконки Heroicons.

## Дизайн

Палитра и шрифты сняты с CSS сайта turan.edu.kz, чтобы интерфейс был узнаваем, но не выдавал себя
за официальный сайт (в подвале – пометка «неофициальный студенческий проект»):

| Роль | Светлая тема | Тёмная тема |
|---|---|---|
| Основной | `#0082C9` | `#36BAF2` |
| Светлый акцент | `#D6E8F5` | – |
| Стальной | `#84ADCA` | `#84ADCA` |
| Фон и бежевые секции | `#F4F3F1`, `#ECE7E0`, `#E7E2DC` | `#0C111D`, `#141B2A` |
| Текст | `#0F172A` | `#F5F7FA` |
| Акцент «кисточка» | `#FFBB00` | `#FFBB00` |

Шрифты – Montserrat (заголовки) и IBM Plex Sans (текст), как на сайте университета, плюс IBM Plex Mono
для цифр телеметрии; подключены локально через `@fontsource` (кириллица и казахские буквы включены,
запросов к Google Fonts нет). Цвета – семантические токены (`bg-surface`, `text-muted`, `bg-primary`…),
их значения переключаются вместе с темой, см. `src/style.css`.

Анимации несут смысл, а не украшают: на главной вопрос «печатается» и по шагам разбирается настоящими
данными модели, в чате раскрывается разбор вопроса, цены и метрики «досчитываются», точки задержек
съезжают по мере новых запросов, нагрузочный тест «проигрывается» по фразам. Системная настройка
«уменьшить движение» отключает анимации.

## Страницы

- **Главная** – живой пример разбора вопроса (токены, леммы, подслова, вероятности тем, ответ),
  как работает бот, темы (клик – вопрос сразу в чат), инструменты, Telegram.
- **Чат** – темы в боковой панели (на телефоне выезжают), ответы со списками и кликабельными ссылками,
  телефонами и почтой; цены программы – таблицей; панель **«Как бот понял вопрос»**: язык, токены и леммы,
  подслова SentencePiece, топ-5 тем с вероятностями ансамбля, e5 и TF-IDF и порогом, сработавшее правило,
  контекст уточнения; «Также спрашивают», копирование, оценка 👍/👎. История – только в браузере.
- **Калькулятор** – 32 программы, уровень, форма обучения, отделение: цена за год и за весь срок,
  сравнение всех форм обучения программы.
- **База знаний** – все 53 ответа с поиском по словам и по смыслу (подсветка совпадений, метка «по смыслу») и фильтром по группам.
- **Производительность** – p50/p95, доля ответов быстрее цели 100 мс, живой график задержек,
  гистограмма, из чего складывается ответ (e5, TF-IDF, остальное), память контейнера, оценки ответов,
  разбивка ответов по правилам (модель, цена программы, умный поиск, уточнение, «не понял»)
  и **нагрузочный тест** по кнопке: 100 фраз через модель, пропускная способность, p50/p95/p99.
- **О проекте** – конвейер, четыре NLP-компонента, сравнение моделей диаграммой с 95% интервалами,
  короткие запросы в трёх конфигурациях сервиса, технологии, ограничения.

При открытии сайт сразу «будит» бэкенд; если бесплатный Render просыпается, показывается баннер.

## Запуск

Только в Docker, локальный `node_modules` не нужен:

```bash
make test   # автотесты Vitest
make build  # проверка типов, сборка Vite и образ nginx
make dev    # dev-сервер на http://localhost:5173 (бэкенд – http://localhost:8000)
make lock   # обновить package-lock.json после правки package.json
```

В образе nginx раздаёт статику и проксирует `/api/*` на контейнер `backend` (docker-compose).
Для GitHub Pages адрес бэкенда на Render передаётся при сборке (`VITE_API_BASE_URL`, `BASE`).

## Структура

```
src/
  api/client.ts      – запросы к API с таймаутом и кодами ошибок
  composables/       – useChat, useKnowledge (темы и цены), useCountUp, useLiveMetrics, useServerStatus,
                       useTheme, useLocale
  components/        – шапка, подвал, пузырь сообщения, график задержек, карточка метрики
    chat/            – разбор вопроса, таблица цен, разметка ответа, панель тем
    home/            – живой пример разбора
    perf/            – гистограмма, кольцо SLA, нагрузочный тест
    about/           – сравнение моделей
  views/             – Главная, Чат, Калькулятор, База знаний, Производительность, О проекте
  locales/           – тексты ru/kk/en (kk и en типизированы по ru – пропущенный ключ ломает сборку)
  utils/             – форматирование, разметка ответа без v-html, логика калькулятора, графики
  examples.ts        – примеры вопросов и данные живого примера (настоящие ответы модели)
```
